# Mini App обменника: бесплатный запуск с автокурсами

## Что в комплекте
- `index.html`: само приложение (пары, калькулятор, наличные по странам, заявка менеджеру @greyderet).
- `rates.json`: курсы. Сейчас стоят тестовые, после первого запуска скрипта заменятся настоящими.
- `update_rates.py`: скрипт, который забирает свежие курсы и записывает их в `rates.json`.
- `update-rates.yml`: расписание для GitHub Actions (запуск скрипта каждые 30 минут).

## Шаг 1. Репозиторий на GitHub
1. Создайте аккаунт на github.com (бесплатно) и новый **публичный** репозиторий, например `exchange-app`.
2. Нажмите Add file → Upload files и загрузите `index.html`, `rates.json`, `update_rates.py`, `README.md`.
3. Add file → Create new file. В поле имени введите `.github/workflows/update-rates.yml` (слэши создадут папки), вставьте туда содержимое файла `update-rates.yml` и нажмите Commit.

## Шаг 2. Включить автообновление
1. Settings → Actions → General → Workflow permissions: выберите **Read and write permissions**, Save.
2. Вкладка Actions → Update rates → Run workflow. Через минуту в репозитории обновится `rates.json` (поле `updated` покажет время).
3. Дальше запуск идёт сам каждые 30 минут. GitHub может запускать с задержкой. Если репозиторий два месяца без активности, расписание отключается: включите его кнопкой на вкладке Actions.

## Шаг 3. Подключить файл курсов к приложению
В `index.html` в блоке `CONFIG` замените `ratesUrl: "rates.json"` на адрес вида
`https://raw.githubusercontent.com/ВАШ_ЛОГИН/exchange-app/main/rates.json`
Этот адрес обновляется сразу после каждого запуска скрипта (с задержкой кэша около 5 минут).

## Шаг 4. Выложить приложение
Settings → Pages → Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
Через пару минут приложение будет по адресу `https://ВАШ_ЛОГИН.github.io/exchange-app/`.
Откройте его в браузере телефона: внизу списка пар должна появиться строка «Курсы обновлены».

## Шаг 5. Telegram
1. В @BotFather: `/newbot`, создайте бота.
2. `/newapp`, выберите бота, укажите ссылку из шага 4. Либо `/mybots` → ваш бот → Bot Settings → Menu Button → ссылка.
3. Откройте бота в Telegram и нажмите кнопку приложения.

## Что настраивается вручную (в блоке CONFIG)
- `managerUsername`: username менеджера без @.
- `rates.usdValue.USD_OLD`: курс «белого» доллара к «синему» (0.97 значит на 3% дешевле).
- `defaultFee`, `cash.fees`: комиссии. `pairList`, `cash.countries`: направления, страны и города.

## Важно
- Фиат берётся из бесплатного источника, который обновляется раз в день. Крипта обновляется при каждом запуске.
- Если источник не отдал какую-то валюту, остаётся прежний курс. Скачок больше 25% (фиат) или 40% (крипта) скрипт не принимает.
- Условия бесплатных API (ссылка на источник, коммерческое использование) проверьте до боевого запуска.
- Курсы наличных между городами не берутся из API, их задаёте вы через комиссии и поправки.
